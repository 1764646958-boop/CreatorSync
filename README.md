# CreatorSync

CreatorSync is a multi-platform content publishing assistant. The current repository contains the initial frontend application shell under `frontend/`.

## Frontend

The frontend is a Next.js App Router application built with TypeScript and TailwindCSS. It provides the initial SaaS-style layout for future content input, AI rewriting, preview, and publishing workflows.

### Dependencies

The frontend uses these primary third-party dependencies:

- `next`
- `react`
- `react-dom`
- `tailwindcss`
- `typescript`
- `postcss`
- `autoprefixer`

### Run Locally

```bash
cd frontend
npm install
npm run dev
```

Then visit the URL printed by Next.js, usually <http://localhost:3000>.

### Environment Variables

No environment variables are required for the current frontend shell.
